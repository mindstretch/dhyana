# Knowledge Base

The distilled, machine-readable layer built from the founder's MA corpus
(Consciousness and Human Potential, MIU). Users never read the source papers —
they experience the knowledge through concepts, experiments, and reflection.

## How this is organized

Knowledge is organized around **human capacities**, not academic courses.
Each capacity file decomposes source material into reusable units:

| Unit | What it is |
|---|---|
| **Concept** | One idea, with a definition and why it matters |
| **Principle** | A developmental claim — how growth actually works |
| **Evidence** | Research findings, tagged with honest strength |
| **Experiment** | An n=1 protocol a user can run on themselves |
| **Reflection** | A prompt that turns experience into structured data |
| **Links** | How concepts relate to each other |

## Evidence honesty (non-negotiable)

Every evidence claim carries a strength tag. This is the product's moat, not a
disclaimer. We inherit the intellectual honesty of the source capstone, which
refused to overclaim.

- `strong` — multiple RCTs / meta-analysis, consistent effects
- `moderate` — RCT(s) with real limitations (small n, self-report, short follow-up)
- `emerging` — suggestive, mixed, or single-study
- `traditional` — grounded in Maharishi Vedic Science / contemplative tradition, not a clinical claim
- `personal` — generated by the user's own experiments (n=1)

Never present `traditional` or `personal` as if it were `strong`.

## Generalization

The source corpus uses trademarked/tradition-specific vocabulary (Transcendental
Meditation, Maharishi Vedic Science). [generalization.md](generalization.md) is
the canonical translation layer that makes the knowledge universal and shippable
— while keeping evidence honest about what was actually studied.
